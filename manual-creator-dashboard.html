Manual do WMK Creator Dashboard

Um guia para canais pequenos. Aprenda a transformar dúvidas dos espectadores em ideias para vídeos, relatórios e melhorias nas suas lives, sem pagar nada.

Abrir dashboard · README do projeto · Manual da API

1. Para quem é?

Para criadores iniciantes, professores, empresas, narradores, gamers e qualquer pessoa que queira entender melhor o próprio público. Não precisa ter centenas de milhares de inscritos. O dashboard não exige conta, API paga ou conexão com YouTube para usar arquivos locais.

Estado do módulo: esta é a versão HTML independente que funciona no navegador. O WMK Screen Studio tem um painel React experimental de análise de chat, mas o dashboard completo ainda não foi incorporado ao aplicativo Tauri nem validado em instalador Windows.

2. Primeira experiência em dois minutos

  1. Abra wmk-creator-dashboard.html em seu navegador.
  2. Clique em Experimentar com dados fictícios.
  3. Veja os números da visão geral e as barras de perguntas frequentes.
  4. Abra Perguntas, Assuntos e Ideias e melhorias.
  5. Abra Importar dados e clique em Gerar relatório HTML para reunião para baixar um relatório independente.

Todos os números demonstrativos são fictícios e servem exclusivamente para aprendizado.

3. Como importar um chat real

Use arquivos CSV/TSV/JSON gerados a partir de dados que você tem autorização para analisar. Um exemplo simples de CSV:

autor;mensagem;data
Ana;Como configurar a webcam?;2026-11-13
Carlos;Muito obrigado pela live!;2026-11-13
Pedro;Tem como gravar uma janela apenas?;2026-11-13

O campo de mensagem é obrigatório. Nome e data são opcionais. Há exemplos fictícios no repositório: chat CSV e métricas CSV.

O protótipo importa até 10 MB por arquivo e limita a quantidade de registros para evitar travamentos. Um chat do YouTube já encerrado não pode ser recuperado integralmente pela API oficial de chat; o coletor ao vivo ainda é uma funcionalidade futura.

4. Quer métricas de vídeos? É opcional

O chat nos ajuda a descobrir perguntas; ele não informa quantas pessoas viram um vídeo. Se tiver dados do YouTube Studio, você pode organizar um arquivo com estas colunas:

date,title,views,impressions,ctr,watch_minutes,subscribers_gained
2026-11-01,Meu primeiro tutorial,84,890,4.2,173,3

Os nomes de coluna em português também são parcialmente aceitos: data, titulo, visualizacoes, impressoes, minutos_assistidos e inscritos_ganhos.

IndicadorO que significa
VisualizaçõesVisualizações informadas no arquivo. Não são estimadas pelo WMK.
ImpressõesExibições da miniatura contabilizadas pela plataforma.
CTRTaxa informada de cliques por impressão. Avalie por vídeo e contexto, não por regra universal.
Minutos assistidosTempo de exibição informado pelo usuário.
Inscritos ganhosInscritos atribuídos ao período/registro, não o total de inscritos do canal.

Para interpretar dados, compare vídeos semelhantes e períodos equivalentes; não é necessário comparar seu canal com milhões de seguidores.

5. Como transformar perguntas em conteúdo melhor

  1. Abra a aba Assuntos e localize os temas que aparecem mais vezes.
  2. Confira as perguntas originais, pois a classificação usa palavras-chave e pode errar.
  3. Escolha uma dúvida prática e crie um vídeo que a resolva de maneira clara.
  4. Na próxima live, responda às perguntas que ficaram pendentes.
  5. Depois compare a recepção do conteúdo com outros vídeos do seu próprio canal.
Exemplo: se vários espectadores perguntarem “Como instalar?”, uma ideia razoável é gravar um tutorial de instalação. Isso não garante mais visualizações, mas atende a uma necessidade real mencionada no chat.

6. IA opcional, usuário no controle

Em IA opcional, o dashboard prepara um prompt baseado nos dados importados. Você pode copiá-lo, remover informações pessoais e colá-lo no provedor que preferir. Não há conexão automática nem coleta de chaves neste HTML.

No futuro, o WMK oferecerá cadastro seguro de provedores, modelos e credenciais individuais. Poderá integrar Ollama local, Groq, OpenAI ou outro serviço compatível, conforme a opção do usuário. O ChatGPT e a API OpenAI são serviços diferentes, com regras próprias de uso/cobrança. Nenhuma contratação será necessária para os recursos locais.

Exemplos de pedidos úteis à IA: organizar temas; gerar roteiro de aula; sugerir descrição e título honesto; criar lista de dúvidas sem resposta; montar agenda de próximos conteúdos.

7. Apresentando resultados para uma equipe

Na aba Importar dados, clique em Gerar relatório HTML para reunião. Você receberá um arquivo autônomo, contendo indicadores e gráficos, que pode ser aberto em outro computador, sem servidor. Para criar seus próprios sistemas, utilize a Audience API com SQLite e a especificação OpenAPI.

A API local exige chave própria e não é liberada à rede por padrão. Controle de usuários, perfis empresariais, HTTPS e permissões por equipe ainda são recursos planejados.

8. Limitações e privacidade

O dashboard não oferece acesso automático a contas, estatísticas oficiais ou bancos de dados de terceiros. Ele usa somente arquivos escolhidos pelo usuário. A análise heurística pode classificar perguntas incorretamente, e dados duplicados ou ausentes podem afetar conclusões.

As informações ficam na memória do navegador durante a sessão; não são enviadas a um servidor pelo HTML. Ao fechar a página, os arquivos carregados não ficam gravados automaticamente. Exporte os resultados que desejar preservar. Use somente dados autorizados e revise nomes e conteúdos antes de compartilhar relatórios.
