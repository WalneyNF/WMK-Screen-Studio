Reuniões e aulas sem complicação

Crie uma sala, compartilhe o link e entre pelo navegador do computador ou celular. Use a infraestrutura Jitsi; o WMK organiza a entrada.

Manual para desenvolvedores · O que é Jitsi?

1. Configurar sala

Para testes, use o público; para uso contínuo em sua aplicação, configure um servidor próprio ou serviço contratado.
Esta opção ainda não atribui papéis de professor ou moderador no servidor.
Abrir reunião em nova aba

Compartilhe apenas com convidados. O link não garante controle de acesso. Ative autenticação, sala de espera e permissões no servidor quando necessário.

2. Reunião integrada (opcional)

Para quem deseja manter a chamada dentro desta página, o Jitsi oferece uma API de incorporação. Em alguns celulares e instalações, abrir em nova aba ou usar o aplicativo oficial pode ser mais compatível.

🌐 Idiomas e acessibilidade

Ative as legendas do Jitsi. Para tradução, o servidor precisa ter transcrição e motor de tradução configurados. Alterar o idioma da interface não traduz a voz.

Se o servidor não tiver transcrição/tradução habilitadas, os botões não conseguem fornecer traduções. Sua voz não é traduzida por este painel. Privacidade e custos dependem do motor de transcrição/tradução configurado.

WMK — Mesa de apresentação

Abra PDF ou imagem no seu computador e use “Compartilhar tela” para mostrar a janela aos participantes. O WMK não envia o arquivo automaticamente; cada participante precisa de acesso autorizado ao documento para recebê-lo.

PowerPoint e Word: abra o arquivo no aplicativo correspondente e compartilhe sua janela. Prévia de PDF depende do visualizador do navegador. Arquivos locais não são publicados nem enviados pelo WMK.

Privacidade: esta página não grava reunião, não salva chat e não recebe senhas. Seu áudio/vídeo é processado pelo servidor Jitsi escolhido. O botão “Encerrar visualização” fecha apenas esta conexão local, não expulsa outras pessoas.
