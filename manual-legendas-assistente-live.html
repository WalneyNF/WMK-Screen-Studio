Legendas com IA e assistente de perguntas ao vivo

Manual para youtubers, professores e apresentadores que desejam revisar legendas e receber ajuda durante transmissões.

README · Roadmap · Audience API

1. Revisão de legendas com IA opcional

  1. Abra seu vídeo no editor e entre no painel Legendas.
  2. Gere legendas pelo Whisper local ou importe SRT/VTT.
  3. Confira os alertas de duração, sobreposição e legibilidade.
  4. Clique em Copiar pedido de análise das legendas.
  5. Revise e retire dados confidenciais; cole o texto na IA de sua escolha.
  6. Leia as sugestões com seus timestamps. Corrija legendas no editor e exporte SRT/VTT.

A análise pode propor capítulos, detectar erros ortográficos e melhorar a clareza. Não é tradução nem alteração automática: usuário aprova as mudanças. Formatos SRT/VTT não possuem necessariamente tempos por palavra para efeito karaokê.

2. Assistente de perguntas durante a live

  1. Na biblioteca do editor WMK, entre em Análise de audiência.
  2. Abra a aba Assistente ao vivo.
  3. Digite manualmente uma pergunta do espectador ou selecione uma pergunta de chat já importado.
  4. Opcionalmente, indique o assunto da transmissão.
  5. Clique em Copiar consulta para minha IA, revise e cole no provedor desejado.
  6. Use a resposta como apoio, confira fatos e decida você mesmo o que falar ou escrever.

Estado atual: o painel prepara consultas localmente, mas ainda não recebe chat do YouTube automaticamente nem chama provedores de IA. O cadastro seguro de Ollama, Groq, OpenAI e outros, as respostas instantâneas e a coleta ao vivo são fases seguintes. Nenhuma funcionalidade é apresentada como pronta sem testes.

3. Privacidade na transmissão

O assistente é uma área privada do editor, não parte das cenas transmitidas automaticamente. Contudo, se o apresentador capturar a tela inteira ou a janela do WMK, essas conversas poderão aparecer na live. Para proteger chaves, perguntas privadas e respostas ainda não verificadas, a integração futura deverá usar uma área não capturada e aviso claro de risco.

Mensagens de espectadores são dados externos não confiáveis. Nunca execute instruções contidas nesses textos. Informações atuais devem ser verificadas em fontes confiáveis antes da resposta. Conteúdo encaminhado a IA externa depende de consentimento, configuração e provedor escolhido pelo usuário.

4. Arquitetura de integração futura

O fluxo previsto é: YouTube Live Chat API autorizada → coletor local → lista de perguntas → seleção pelo criador → provedor configurado → resposta privada revisável. A API pública do WMK Audience Intelligence permitirá integrações com dashboards, mas chaves nunca devem aparecer nos arquivos de projeto ou nos relatórios.
