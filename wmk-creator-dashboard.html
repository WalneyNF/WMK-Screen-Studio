Visualizações por vídeo informado

O que é CTR, impressão e tempo de exibição?

CTR: percentual de impressões da miniatura que geraram visualizações conforme a definição do YouTube. Impressões: vezes em que a miniatura foi mostrada em locais contabilizados pela plataforma. Tempo de exibição: minutos assistidos, se exportados. Esses indicadores exigem os dados originais do canal.

Não compare a CTR de vídeos com públicos e origens muito diferentes sem contexto. Não existe uma meta universal.

Seu assistente de IA, do seu jeito

Você poderá usar Ollama local, OpenAI, Groq ou outro provedor compatível quando a integração de credenciais estiver implementada no aplicativo. Aqui o painel prepara um prompt para você copiar e colar no serviço que preferir.

Importe seus dados

Chat: CSV ou JSON com a coluna mensagem / message. Campos opcionais: autor e data.

Métricas: CSV ou JSON com colunas title, date, views, impressions, ctr, watch_minutes, subscribers_gained (nomes equivalentes em português também são aceitos).

Você pode começar somente pelo chat. Se não tiver métricas, os cartões correspondentes mostrarão “—”, nunca números inventados.

Até 10 MB por arquivo; até 30 mil mensagens e 5 mil linhas de métricas. Dados ficam em memória no navegador, sem servidor. Fechar a página elimina os dados não exportados.

Primeiros passos para canais pequenos

1. Comece pelo exemplo

Clique no botão “Experimentar com dados fictícios”. Assim você entende cada tela sem conectar sua conta.

2. Importe comentários ou chat autorizado

Abra a aba Importar. O arquivo deve ter uma coluna de mensagem. Replays do YouTube não garantem exportação completa pela API após a live; futuramente teremos um coletor durante a transmissão.

3. Veja as perguntas

As dúvidas mais comuns podem virar o próximo vídeo. Mesmo cinco perguntas já são um começo útil.

4. Se tiver métricas, importe seus vídeos

Compare sua evolução com seus próprios conteúdos, em períodos equivalentes, e não com canais famosos.

5. Prepare uma reunião

Gere um HTML com indicadores e gráficos ou exporte JSON para aplicações externas. Para relatórios persistentes e API, consulte o módulo Audience API com SQLite.

6. Use IA se quiser

O sistema oferece um prompt que você pode revisar. Nenhum provedor é obrigatório. Credenciais e possíveis cobranças pertencem à escolha do usuário.
